# 🛩️ TAPPY STRIKER: ANTEK ASING BUSTER

Game web mini bergaya **Tappy Plane** di mana pemain mengendalikan pesawat tempur Garuda-01 untuk menembak jatuh armada antek-antek asing yang memiliki livery khusus karikatur **Donald Trump sedang teriak** di badan pesawatnya.

---

## 🎮 Kontrol Game (Keyboard & Mouse / Touch)

| Tombol / Mouse | Aksi | Keterangan |
| :---: | :---: | :--- |
| **`KLIK MOUSE KIRI` / `S`** | **Tembak** | Menembakkan peluru ke musuh (bisa klik atau tahan untuk rapid-fire) |
| **`KLIK MOUSE KANAN` / `R`** | **Reload** | Mengisi ulang amunisi magazine (15 peluru) |
| **`W` / `▲`** | **Naik (Smooth)** | Terbang naik secara halus dan mulus tanpa loncatan tajam |
| **`▼` / `X`** | **Turun (Smooth)**| Terbang turun secara halus |
| **`D`** | **Maju** | Menambah kecepatan pesawat maju ke depan |
| **`A`** | **Mundur** | Mengerem & memundurkan pesawat ke belakang |
| **`P` / `Esc`** | **Pause** | Menjeda & melanjutkan permainan |

> Tersedia juga tombol virtual di bagian bawah layar untuk pengguna mouse, tablet, maupun layar sentuh. Context menu klik kanan otomatis dinonaktifkan di game agar reload berjalan instan tanpa gangguan.

---

## ✨ Fitur Utama

1. **Penerbangan Halus Aerodinamis (Zero-Gravity)**:
   - Gravitasi pesawat telah dihilangkan sehingga pesawat tidak jatuh terus-menerus dan melayang stabil di udara.
   - Tombol `W` kini menggerakkan pesawat naik secara mulus (*smooth acceleration & damping*) tanpa hentakan/loncatan tajam.
   - Tersedia tombol `▼` / `X` untuk turun dengan mulus.

2. **Antek Asing dengan Livery Donald Trump Teriak**:
   - Setiap pesawat musuh memiliki corak/livery Donald Trump sedang teriak dengan mulut terbuka di badan pesawat.
   - Dilengkapi bilah nyawa darah (**Health Bar**) di atas masing-masing pesawat musuh.

3. **Mekanik "Jatuh Mati" (Crash & Burn)**:
   - Ketika darah musuh habis, pesawat musuh tidak langsung hilang biasa, melainkan oleng, moncong menukik tajam ke bawah, berputar lepas kendali, mengeluarkan asap hitam pekat dan kobaran api, lalu menghujam tanah dan meledak dahsyat (*screen shake* + suara ledakan)!

4. **Amunisi & Reload Realistis**:
   - Indikator magazine 15 peluru dengan visualisasi amunisi di HUD.
   - Peringatan visual berkedip saat amunisi kosong.
   - Tekan `R` untuk memicu indikator reload putar dan efek suara mekanis.

5. **Desain & Tipografi**:
   - **Warna Aksen Kuning Terang** (*Vibrant Cyber Yellow `#FFE81F`*) pada HUD, amunisi, garis aksen, dan laser peluru.
   - **Maksimal 2 Font**:
     - `Chakra Petch` (Military Arcade Headers & HUD)
     - `Plus Jakarta Sans` (UI Body & Subtitle)

6. **Audio Terintegrasi (Web Audio API)**:
   - Efek suara tembakan, kepakan mesin, reload, suara peluit pesawat jatuh, dan ledakan tanpa perlu file audio eksternal.
   - Tombol toggle Mute / Unmute audio di header.

